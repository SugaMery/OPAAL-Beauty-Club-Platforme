# OPAAL-Beauty-Club-Platforme

Site web et espace propriétaire d'OPAAL Beauty Club (Amelkis III, Marrakech) : site bilingue français / anglais en Angular, API PHP avec base SQLite.

- `2-code-source/frontend` : site Angular (pages, espace propriétaire, traductions)
- `2-code-source/api` : API PHP (contenu, formulaires, e-mails, blog, SEO)
- `GUIDE-INSTALLATION.txt` : mise en ligne et utilisation

Configuration : copier `2-code-source/api/config.example.php` en `config.php` et le compléter. Ce fichier contient des secrets et n'est pas versionné.
